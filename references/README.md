# References

[`references.bib`](references.bib) holds every work cited in the [literature review](../research/literature-review/README.md) (BibTeX). Each entry was verified on 2026-11-20 against at least one primary metadata source (arXiv API, Crossref, or the publisher / standards-body page); the `note` field records how. Venues taken only from an arXiv author comment are marked "venue per arXiv comment". Candidates that could not be verified are not in the file; they are listed in §9 of the review.

Cited works keep their own licences and copyrights; see [`../LICENSING.md`](../LICENSING.md).

To cite this repository itself, use [`../CITATION.cff`](../CITATION.cff).
