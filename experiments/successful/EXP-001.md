**Evidence label:** `OBSERVED`  
**Outcome class (this repository):** `successful`

**Model:** Qwen2.5-Coder-7B Q4 (local)

## Hypothesis

A scaffold + small local model (7B) can reproduce most finding families of an Opus 4.6 Juice Shop run.

## Setting

| Field | Value |
|---|---|
| Target / environment | OWASP Juice Shop (+ VAmPI); consumer laptop GPU (8 GB) |
| Method | 7 deterministic detectors + 24 playbooks driven by Qwen2.5-Coder-7B Q4; scored by family against an Opus 4.6 demo run (57 findings -> 31 families) |
| Code version | research prototype outside the product repositories (no product commit) |
| Budget | — |
| Real cost | USD 0 cloud |
| Tokens | — |

## Result

24/27 families (88%) covered, 31 raw findings; 0 FP after evidence gate (RESULTS.md table)

**False positives / false links:** 0 after proof gate; naive detector had ~14 FP on SPA before gate; one lightpanda DOM-XSS verification FP rejected

## Limitations

Prototype outside the product; ground truth = another LLM run, not a sealed truth; Juice Shop solutions are public (contamination risk)

## Decision

Research only; not shipped
